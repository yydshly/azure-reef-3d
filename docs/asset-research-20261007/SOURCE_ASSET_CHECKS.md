# Two bounded source-asset checks — 2026-10-07

These checks support the current reference-led asset strategy. They are not a claim that a complete Caribbean textured scan is the only route to any visual improvement, or that no other public assets exist. Existing production geometry is unchanged.

## Bremen / ABC Islands

Primary record: https://zenodo.org/records/17513294
Creator: Patrick Boyden, Center for Marine Environmental Sciences, University of Bremen
Declared license: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/

The full ZIP64 central directory was verified from a 131,072-byte range, without downloading the 17.5 GB archive. All 76 entries were accounted for: 3 folders, 69 TIFF-named entries (one empty), 4 macOS sidecars. No mesh, point cloud, reconstruction project or source photographs were released in that archive. Metadata supplies metric survey/depth/resolution context, but the distributed orthomosaics do not supply true 3D scene geometry. TIFF image pixels were not inspected, and no raster was adopted as a world surface or background.

## POSER / NAUTILUS

Primary paper: https://repository.library.noaa.gov/view/noaa/69815/noaa_69815_DS1.pdf
Publisher: https://isprs-archives.copernicus.org/articles/XLVIII-2-2024/265/2024/
Official portal: https://nautilus-isprs.fbk.eu/dataset-collection/nautilus-web-portal

The paper/publisher page provides no verified reef asset download or code repository; precompiled Blender scenes are described as future releases. Its actual reef example is a 55 × 7 m Moorea (French Polynesia) scan, while other examples reuse Smithsonian specimens. The article's CC BY 4.0 does not establish a reusable license for those underlying models, their scene units, or Caribbean provenance. One bounded retry of the same official page returned HTTP 200. Its HTML embeds an ArcGIS web map but lists no direct POSER/Moorea model package or asset license. The public embedded map and 18 deduplicated relevant/geographic entries were subsequently inspected. No suitable mesh was verified. The earlier cancelled read process was not a site access prohibition. See research-manifest.json for retrieval evidence.

## Current boundary

Neither checked lead currently supplies a verified directly reusable true 3D Caribbean reef asset. For this particular data-led strategy, a released model or reconstruction input still needs its own reuse license, usable geometry/texture, scale information and appropriate geographic provenance. Other source-informed design approaches remain possible, but they must pass visible quality checks; the two rejected local deformation methods do not establish that every budget-compatible model would fail.

## Final linked-map findings

- [Red Sea mapping data](https://datadryad.org/dataset/doi:10.5061/dryad.6m905qg2p): CC0 is declared, but the release lists orthomosaics, elevation rasters and classification vectors, not a ready mesh or raw reconstruction photos. Archive contents were not downloaded. Its Red Sea location also differs from the current scene.
- [Scott Reef survey](https://marine.acfr.usyd.edu.au/datasets/): Australian 75 × 50 m stereo-imagery reconstruction input, about 22 GB. No ready mesh or explicit commercial asset reuse license was verified; no package was downloaded.
- The map's regional GoPro entry describes video and calibration. Its source returned HTTP 502, so contents/license remain unverified.
- The bounded map queries found no POSER/Moorea asset entry. These findings close this source chain, not every possible asset source or design method.
